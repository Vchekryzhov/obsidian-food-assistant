# Контекст проекта

## Термины

- **Namespace SolidAlarm** — верхнеуровневая папка `solidalarm` в vault, предназначенная для модулей SolidAlarm.
- **Модуль** — самостоятельная функциональная область внутри namespace, например `Питание`; он объединяет свои инструкции и пользовательские данные.
- **Управляемые инструкции** — файлы модуля, которые пакет может обновлять только при отсутствии пользовательских изменений.
- **Пользовательские данные** — рецепты, продукты, меню, инвентарь, история и другие записи, которые установщик не перезаписывает.

## Инварианты

- Каждый модуль находится внутри namespace SolidAlarm.
- Управляемые инструкции и пользовательские данные могут находиться в одном каталоге модуля, но различаются политикой файла.
- Добавление или обновление модуля не должно уничтожать пользовательские данные.
