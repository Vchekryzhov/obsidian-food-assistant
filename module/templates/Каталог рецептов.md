# Каталог рецептов

Карточки в `{{dataRoot}}/Рецепты` — источник истины. Таблица строится Dataview из frontmatter и обновляется автоматически.

```dataview
TABLE WITHOUT ID
  file.link AS "Рецепт",
  category AS "Категория",
  main_ingredient AS "Основной продукт",
  status AS "Статус",
  total_time_min AS "Время, мин",
  equipment AS "Оборудование",
  data_completeness AS "Полнота"
FROM "{{dataRoot}}/Рецепты"
WHERE type = "recipe"
SORT category ASC, file.name ASC
```
