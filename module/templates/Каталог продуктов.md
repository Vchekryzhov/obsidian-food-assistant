# Каталог продуктов

Карточки в `{{dataRoot}}/Продукты` содержат справочные свойства продуктов и варианты товаров. Фактические остатки ведутся отдельно в [[{{dataRoot}}/Инвентарь]].

```dataview
TABLE WITHOUT ID
  file.link AS "Продукт",
  category AS "Категория",
  default_storage AS "Обычно хранится",
  data_completeness AS "Полнота"
FROM "{{dataRoot}}/Продукты"
WHERE type = "product"
SORT category ASC, file.name ASC
```
